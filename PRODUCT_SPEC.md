## 1. Product Vision

Renewal Loop treats apparel as a **long-term hardware system**, not a disposable consumable. Every garment is engineered around a modular architecture: high-wear components — elbows, knees, collars, cuffs, zippers, pockets — are **interchangeable panels** that snap in and out in seconds. When a collar frays or a zipper fails, the user replaces the $15 panel, not the $120 garment.

This shifts the garment from a one-time purchase to a **repairable platform** with a multi-year service life:

- **Garment body** = durable chassis (recycled polyester canvas, 5+ year design life)
- **Panels** = consumable, replaceable, upgradable modules
- **Refurbish Plan** = subscription covering periodic panel replacements and repairs
- **Loop ecosystem** = color swaps, seasonal updates, B2B customization, AI-generated custom patterns

The result: less waste, lower lifetime cost per wearer, and a revenue model built on maintenance and customization rather than planned obsolescence.

## 2. Snap-and-Secure Mechanism

The core technology is the **Snap-and-Secure** seam system — a standardized attachment interface that lets any compatible panel lock into any compatible garment channel.

### 2.1 Design Overview

| Component | Material | Function |
|---|---|---|
| **Magnetic snap buttons** | 304 stainless steel, nickel-free, 10mm diameter | Provide tactile auto-aligning snap closure; magnets pull panel into correct position before mechanical lock engages |
| **Reinforced fabric channel** | Double-layer recycled polyester canvas with woven binding tape | Lines the garment edge; receives the panel's snap studs and distributes load across the seam |
| **Snap studs (panel side)** | Stainless steel, riveted through reinforced patch | Permanently attached to panel; protrude through channel grommets and lock into receptacles |
| **Snap receptacles (garment side)** | Stainless steel, seated in channel grommets | Embedded in garment channel; receive panel studs and provide mechanical retention |
| **Retention loop** | Woven binding tape, hook-and-loop strip | Secondary backup retention along channel perimeter to prevent panel pull-through under load |

### 2.2 How It Works

1. **Align** — The user positions the replacement panel along the garment's channel opening. Embedded magnets in the snap buttons auto-align the panel studs toward the garment receptacles.
2. **Snap** — Firm pressure clicks each snap stud through the channel grommet into its receptacle. A tactile "click" confirms mechanical lock.
3. **Secure** — The user presses the retention loop closed along the channel perimeter (hook-and-loop backup), eliminating any gap.
4. **Release** — To remove, the user peels back the retention loop and pops each snap with a flat tool or thumbnail. The panel releases cleanly for swap or replacement.

### 2.3 Interchangeable Panel Zones

Panels are designed for specific high-wear or high-customization zones:

| Zone | Panel Type | Replaceable? | Primary Use Case |
|---|---|---|---|
| Elbow | Elbow panel | Yes | Elbow blow-out, abrasion repair |
| Knee | Knee panel | Yes | Knee wear, workwear reinforcement |
| Collar | Collar panel | Yes | Collar fray, color/style swap |
| Cuff | Cuff panel | Yes | Cuff wear, length/color change |
| Zipper | Zipper panel | Yes | Zipper failure (most common garment failure point) |
| Pocket | Pocket panel | Yes | Pocket tear, add/remove pockets, utility config |

All panels use the same snap-and-secure interface standard so a user only learns one attachment method.

### 2.4 Design Constraints

- **Wash-safe:** Snaps and channel survive 50+ machine wash cycles (cold, gentle). Panels rated for 100+ cycles.
- **Skin-contact safe:** All snap hardware is nickel-free 304 stainless; channel binding is OEKO-TEX certified.
- **Load-rated:** Elbow and knee panels rated to 40N pull-through resistance; collar/cuff/zipper rated to 15N.
- **Field-swappable:** No tools required for panel swap; optional flat pry tool included in Refurbish Kit for tight snaps.

## 3. Panel Types

### 3.1 Elbow Panel

- **Shape:** Contoured oval, pre-curved to match elbow bend
- **Reinforcement:** Double-layer canvas with inner abrasion pad
- **Sizes:** S, M, L, XL (see §5 Sizing)
- **Colors:** Black, navy, olive, charcoal, sand (see §6 Colors)
- **Snap points:** 6 snaps (3 top, 3 bottom along channel)
- **Use case:** Workwear, outdoor, high-abrasion environments

### 3.2 Knee Panel

- **Shape:** Contoured rectangle, pre-curved to match knee
- **Reinforcement:** Triple-layer canvas with optional hard-shell insert pocket
- **Sizes:** S, M, L, XL
- **Colors:** Black, navy, olive, charcoal, sand
- **Snap points:** 8 snaps (4 top, 4 bottom)
- **Use case:** Workwear, trades, outdoor

### 3.3 Collar Panel

- **Shape:** Curved band, wraps neckline
- **Reinforcement:** Single-layer canvas with binding edge
- **Sizes:** S/M, L/XL (two size brackets — collar variance is low)
- **Colors:** Black, navy, olive, charcoal, sand
- **Snap points:** 4 snaps (2 each side)
- **Use case:** Collar fray, style/color swap, corporate/uniform branding

### 3.4 Cuff Panel

- **Shape:** Tubular band, wraps wrist/ankle opening
- **Reinforcement:** Single-layer canvas with elastic inner band
- **Sizes:** S/M, L/XL
- **Colors:** Black, navy, olive, charcoal, sand
- **Snap points:** 3 snaps
- **Use case:** Cuff wear, length adjustment, color change

### 3.5 Zipper Panel

- **Shape:** Full-length placket strip including #5 YKK zipper
- **Reinforcement:** Double-layer canvas backing behind zipper tape
- **Sizes:** S, M, L, XL (length-scaled)
- **Colors:** Black, navy, olive, charcoal, sand
- **Snap points:** 10 snaps (5 each side of zipper)
- **Use case:** Zipper failure replacement — the #1 garment failure globally

### 3.6 Pocket Panel

- **Shape:** Modular rectangle with snap-in utility pockets
- **Reinforcement:** Double-layer canvas, bartack reinforced entry
- **Sizes:** Universal (one size, adjustable channel)
- **Colors:** Black, navy, olive, charcoal, sand
- **Snap points:** 4 snaps (corner-mounted)
- **Use case:** Add/remove pockets, reconfigure utility layout, replace torn pockets

## 4. Materials

### 4.1 Primary Fabric

| Material | Spec | Source |
|---|---|---|
| **Recycled polyester canvas** | 600D, 8 oz/yd², rPET certified (GRS) | Post-consumer PET bottles |
| **Binding tape** | Woven polyester, 20mm, OEKO-TEX Std 100 | Standard textile supplier |
| **Thread** | Bonded nylon #69, UV-stabilized | Reinforced stitching all seams |
| **Reinforcement patch** | Second layer 600D canvas at stress points | Same rPET source |

### 4.2 Hardware

| Component | Material | Spec |
|---|---|---|
| **Snap buttons** | 304 stainless steel, nickel-free | 10mm diameter, magnetic core |
| **Snap receptacles** | 304 stainless steel | Embedded in channel grommet |
| **Zipper** | YKK #5 molded tooth | Auto-lock slider |
| **Hook-and-loop** | 3M dual-lock, 20mm strip | Secondary retention |
| **Elastic (cuff)** | Rubber-core woven elastic | 15mm, 1.5mm gauge |

### 4.3 Sustainability

- **Fabric:** 100% recycled polyester (GRS certified) — each garment uses ~18-22 post-consumer PET bottles
- **Hardware:** Stainless steel is 90% recyclable; snaps are removable for end-of-life sorting
- **Panels:** Replaced individually — only the worn component is discarded, not the whole garment
- **Packaging:** Recycled kraft mailer, no plastic, soy-based ink
- **End of life:** Garment body return program → fabric recycled into new canvas feedstock

## 5. Sizing

### 5.1 Cross-Size Panel Interchangeability

Panels must be **interchangeable across garment sizes** via an **adjustable channel**. A size S elbow panel snaps into a size S, M, or L garment because the channel is designed with a telescoping overlap zone.

| Panel Size | Fits Garment Size | Mechanism |
|---|---|---|
| S | S, M | Channel overlap zone absorbs 1 size delta |
| M | S, M, L | Channel overlap zone absorbs 1 size delta either direction |
| L | M, L, XL | Channel overlap zone absorbs 1 size delta either direction |
| XL | L, XL | Channel overlap zone absorbs 1 size delta |

### 5.2 Adjustable Channel Design

- The garment channel is **wider than the panel snap row** by 15mm per side.
- An inner **telescoping binding strip** slides to close any gap when a smaller panel is installed in a larger garment.
- Snap receptacles are spaced on a **standard 25mm pitch** across all sizes — only the count varies (smaller garments have fewer snaps, not closer spacing).
- This means a user can buy a size M garment now and a size L garment later, and **reuse all their existing panels**.

### 5.3 Garment Sizing Chart

## 6. Color Options

All panels and garments are available in the same 5-color palette, enabling mix-and-match customization:

| Color Name | Hex | Description |
|---|---|---|
| **Black** | `#1A1A1A` | Matte black, all-season |
| **Navy** | `#1B2838` | Deep navy blue |
| **Olive** | `#4B5320` | Military olive drab |
| **Charcoal** | `#36454F` | Slate charcoal grey |
| **Sand** | `#C2B280` | Desert tan / light khaki |

### 6.1 Color Swapping as a Feature

Because panels are interchangeable, users can:

- **Tone-on-tone:** Match all panels to garment color for a clean look
- **Contrast panels:** Mix colors (e.g., black garment + sand elbow/knee panels) for a custom aesthetic
- **Seasonal refresh:** Swap to a new color palette without buying a new garment
- **Team/brand:** Corporate or team colors via B2B custom panel runs
